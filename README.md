# Artist Portfolio Landing Page

A responsive landing page for a visual artist built with HTML, CSS, and vanilla JavaScript. 
Focused on clean UI, layout practice, and responsive design.
---

## Project Purpose

This project was created for learning and portfolio purposes.  
It helps practice:

- Semantic HTML structure
- Flexbox and CSS Grid
- Responsive design (mobile-first thinking)
- BEM methodology
- Basic UI interactions

---

### 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)
